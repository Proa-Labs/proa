The showcase reproduces the underlying Sentry product UI, omitting the green
editorial callouts baked into the blog images. Fixture names and attributes are
based on the article's checkout demo: a React frontend continues a trace into a
FastAPI backend instrumented with OpenTelemetry, and an OTel Collector forwards
traces and logs to Sentry.

The source images were downloaded to a temporary inspection directory but are
not redistributed by this repository. The page uses local CSS shapes and text,
with no production Sentry assets or API traffic.
