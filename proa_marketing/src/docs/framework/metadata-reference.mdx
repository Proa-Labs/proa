Use `cx.head_mut()` inside a layout or Page's `render_head` hook. Each example below puts the mutation directly above its generated HTML. See [Metadata and OG images](/docs/framework/metadata) to set up a document.

Examples are independent: they use a fresh managed document, `https://shop.example` as the public origin, `/` as the mount, and no default fields or CSP nonce unless stated otherwise. Output shows only the generated tags, with line breaks added for readability. Charset, viewport, and other manual tags remain in your document template.

## Apply a metadata object

Use `metadata` to set several fields in one call:

```rust filename="render_head"
use proa_core::HeadMetadata;

cx.head_mut().metadata(HeadMetadata {
    title: Some("Trail & Travel".into()),
    description: Some("Built for the outdoors.".into()),
    canonical: Some("/products/trail-jacket".into()),
    ..Default::default()
})?;
```

```html filename="Generated HTML"
<title>Trail &amp; Travel</title>
<link rel="canonical" href="https://shop.example/products/trail-jacket">
<meta name="description" content="Built for the outdoors.">
```

`HeadMetadata` supports `title`, `description`, `title_template`, `canonical`, and `open_graph`. `None` preserves the inherited value; use the individual `clear_*` methods to remove a field. The whole patch is validated before any field changes. Its title uses the nearest ancestor template, just like `title(...)`.

## Document metadata

### title

Set the document title. Text is escaped when it is written to HTML.

```rust filename="render_head"
cx.head_mut().title("Trail & Travel")?;
```

```html filename="Generated HTML"
<title>Trail &amp; Travel</title>
```

### description

Set the description shown to search engines and link previews.

```rust filename="render_head"
cx.head_mut().description("Lightweight layers for everyday adventures.")?;
```

```html filename="Generated HTML"
<meta name="description" content="Lightweight layers for everyday adventures.">
```

### canonical

Resolve a canonical path against the trusted public origin.

```rust filename="render_head"
cx.head_mut().canonical("/products/trail-jacket")?;
```

```html filename="Generated HTML"
<link rel="canonical" href="https://shop.example/products/trail-jacket">
```

Pass paths relative to the configured public mount. Do not first prefix them with `cx.request().url(...)`.

### title_template

An ancestor can provide a title template. A descendant supplies the title.

```rust filename="render_head"
// Layout hook
cx.head_mut().title_template("%s | Acme")?;

// Page hook
cx.head_mut().title("Trail Jacket")?;
```

```html filename="Generated HTML"
<title>Trail Jacket | Acme</title>
```

Dynamic routes work the same way: a Page at `/products/:id` or `/blog/:slug` uses `cx.param(...)` to load its display title and passes it to `title(...)` or `metadata(...)`. The template formats that title; it does not infer a title from the URL.

A template must contain exactly one `%s`. The nearest ancestor template applies once. A template set in a hook applies to descendants, not to a title set in that same hook.

### absolute_title

Bypass an inherited title template for this title.

```rust filename="render_head"
// Layout hook
cx.head_mut().title_template("%s | Acme")?;

// Page hook
cx.head_mut().absolute_title("Checkout")?;
```

```html filename="Generated HTML"
<title>Checkout</title>
```

### clear_title_template

Stop a template from being inherited by deeper descendants.

```rust filename="render_head"
// Root layout hook
cx.head_mut().title_template("%s | Acme")?;

// Nested layout hook
cx.head_mut().clear_title_template()?;

// Page hook
cx.head_mut().title("Checkout")?;
```

```html filename="Generated HTML"
<title>Checkout</title>
```

Clearing a template affects descendants. To bypass an ancestor template for a title in the current hook, use `absolute_title`.

## Named meta tags

### meta

Set a named meta tag. Setting the same name again replaces its value; names are matched without case sensitivity.

```rust filename="render_head"
cx.head_mut().meta("robots", "index, follow")?;
cx.head_mut().meta("author", "Acme")?;
```

```html filename="Generated HTML"
<meta name="robots" content="index, follow">
<meta name="author" content="Acme">
```

`description(value)` is shorthand for `meta("description", value)`. Use `open_graph` for Open Graph properties.

### Twitter cards

Use named meta tags for a Twitter/X card.

```rust filename="render_head"
cx.head_mut().meta("twitter:card", "summary_large_image")?;
cx.head_mut().meta("twitter:title", "Trail Jacket")?;
cx.head_mut().meta("twitter:image", "https://shop.example/og/trail-jacket.png")?;
```

```html filename="Generated HTML"
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Trail Jacket">
<meta name="twitter:image" content="https://shop.example/og/trail-jacket.png">
```

`meta` stores text; it does not resolve URL values or copy Open Graph fields. Supply an absolute URL for `twitter:image`.

### Clear inherited metadata

Clear only the inherited fields you want to remove. Other metadata stays in place.

```rust filename="render_head"
// Layout hook
cx.head_mut().title("Shop")?;
cx.head_mut().description("Browse our products.")?;
cx.head_mut().canonical("/products")?;
cx.head_mut().meta("robots", "noindex")?;
cx.head_mut().meta("author", "Acme")?;

// Page hook
cx.head_mut().clear_title()?;
cx.head_mut().clear_description()?;
cx.head_mut().clear_canonical()?;
cx.head_mut().remove_meta("robots")?;
```

```html filename="Generated HTML"
<meta name="author" content="Acme">
```

`clear_title`, `clear_description`, `clear_canonical`, and `remove_meta` suppress inherited values. Omitting a mutation keeps the inherited value.

## Open Graph

Use `OpenGraph` and `HeadMedia` from `proa_core` for these builders.

### open_graph

Enable Open Graph and reuse the final document title, description, and canonical URL.

```rust filename="render_head"
cx.head_mut().title("Trail Jacket")?;
cx.head_mut().description("Built for the outdoors.")?;
cx.head_mut().canonical("/products/trail-jacket")?;
cx.head_mut().open_graph(
    OpenGraph::new().kind("product").site_name("Acme"),
)?;
```

```html filename="Generated HTML"
<title>Trail Jacket</title>
<meta name="description" content="Built for the outdoors.">
<link rel="canonical" href="https://shop.example/products/trail-jacket">
<meta property="og:title" content="Trail Jacket">
<meta property="og:description" content="Built for the outdoors.">
<meta property="og:url" content="https://shop.example/products/trail-jacket">
<meta property="og:site_name" content="Acme">
<meta property="og:type" content="product">
```

Open Graph is opt-in. `OpenGraph::new()` enables it. Unspecified title, description, and URL fall back to the final document fields at emission; a templated title includes its template.

### A different social title

Set an Open Graph title without changing the document title.

```rust filename="render_head"
cx.head_mut().title("Trail Jacket")?;
cx.head_mut().open_graph(
    OpenGraph::new().title("Meet your new everyday jacket"),
)?;
```

```html filename="Generated HTML"
<title>Trail Jacket</title>
<meta property="og:title" content="Meet your new everyday jacket">
```

### Open Graph images

Describe an existing image with its URL, alternative text, and dimensions.

```rust filename="render_head"
cx.head_mut().open_graph(
    OpenGraph::new().images([
        HeadMedia::new("/og/trail-jacket.png")
            .mime_type("image/png")
            .alt("Trail Jacket in forest green")
            .dimensions(1200, 630),
    ]),
)?;
```

```html filename="Generated HTML"
<meta property="og:image" content="https://shop.example/og/trail-jacket.png">
<meta property="og:image:type" content="image/png">
<meta property="og:image:alt" content="Trail Jacket in forest green">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
```

Import `HeadMedia` and `OpenGraph` from `proa_core`. Proa resolves the image URL and emits its metadata; it does not generate or resize the image. `secure_url(...)` adds an optional `og:image:secure_url`.

### Replace inherited images

An images list replaces the whole inherited list.

```rust filename="render_head"
// Layout hook
cx.head_mut().open_graph(
    OpenGraph::new().images([HeadMedia::new("/og/shop.png")]),
)?;

// Page hook
cx.head_mut().open_graph(
    OpenGraph::default().images([HeadMedia::new("/og/trail-jacket.png")]),
)?;
```

```html filename="Generated HTML"
<meta property="og:image" content="https://shop.example/og/trail-jacket.png">
```

`OpenGraph::default()` is a patch: it changes only the supplied fields. It does not enable a previously disabled graph. Use `images([])` to remove inherited images.

### Open Graph locales

Set a primary locale and alternate locales.

```rust filename="render_head"
cx.head_mut().open_graph(
    OpenGraph::new()
        .locale("en_US")
        .alternate_locales(["fr_FR", "es_ES"]),
)?;
```

```html filename="Generated HTML"
<meta property="og:locale" content="en_US">
<meta property="og:locale:alternate" content="fr_FR">
<meta property="og:locale:alternate" content="es_ES">
```

The alternate locale list replaces the whole inherited list. Pass an empty typed list, such as `[] as [&str; 0]`, to clear it.

### Audio and video

Audio and video use the same `HeadMedia` records as images.

```rust filename="render_head"
cx.head_mut().open_graph(
    OpenGraph::new()
        .audio([HeadMedia::new("/media/trail.mp3").mime_type("audio/mpeg")])
        .video([HeadMedia::new("/media/trail.mp4").dimensions(1280, 720)]),
)?;
```

```html filename="Generated HTML"
<meta property="og:audio" content="https://shop.example/media/trail.mp3">
<meta property="og:audio:type" content="audio/mpeg">
<meta property="og:video" content="https://shop.example/media/trail.mp4">
<meta property="og:video:width" content="1280">
<meta property="og:video:height" content="720">
```

Each audio or video list replaces its inherited list. Related properties stay with their media record.

### Clear an Open Graph fallback

Explicitly clear a social field to suppress its fallback while leaving the document field alone.

```rust filename="render_head"
cx.head_mut().title("Trail Jacket")?;
cx.head_mut().description("Built for the outdoors.")?;
cx.head_mut().open_graph(OpenGraph::new().clear_title())?;
```

```html filename="Generated HTML"
<title>Trail Jacket</title>
<meta name="description" content="Built for the outdoors.">
<meta property="og:description" content="Built for the outdoors.">
```

An omitted social field inherits or falls back; a cleared field stays absent. The same pattern applies to `clear_description`, `clear_url`, `clear_site_name`, `clear_determiner`, `clear_kind`, and `clear_locale` on `OpenGraph`.

### Disable Open Graph

Suppress the whole graph without changing ordinary document metadata.

```rust filename="render_head"
cx.head_mut().title("Checkout")?;
cx.head_mut().open_graph(OpenGraph::new().kind("website"))?;
cx.head_mut().open_graph(OpenGraph::default().enabled(false))?;
```

```html filename="Generated HTML"
<title>Checkout</title>
```

## Stylesheets and scripts

### stylesheet

Register a stylesheet in a typed resource slot.

```rust filename="render_head"
#[derive(PartialEq, Eq)]
enum Style { Theme }

cx.head_mut().stylesheet(Style::Theme, "/styles/theme.css")?;
```

```html filename="Generated HTML"
<link rel="stylesheet" href="https://shop.example/styles/theme.css">
```

### Replace a stylesheet

Writing the same slot again changes its URL without emitting a second tag.

```rust filename="render_head"
#[derive(PartialEq, Eq)]
enum Style { Theme }

cx.head_mut().stylesheet(Style::Theme, "/styles/base.css")?;
cx.head_mut().stylesheet(Style::Theme, "/styles/shop.css")?;
```

```html filename="Generated HTML"
<link rel="stylesheet" href="https://shop.example/styles/shop.css">
```

A slot is identified by its resource family, enum type, and variant. Different slots may intentionally use the same URL.

### module

Register an external module script.

```rust filename="render_head"
#[derive(PartialEq, Eq)]
enum Script { Site }

cx.head_mut().module(Script::Site, "/scripts/site.js")?;
```

```html filename="Generated HTML"
<script type="module" src="https://shop.example/scripts/site.js">
</script>
```

When a CSP nonce is installed before managed-head initialization, Proa adds it to resource tags automatically. The output above assumes no nonce.

### Remove a resource

Remove a stylesheet or module by its slot key.

```rust filename="render_head"
#[derive(PartialEq, Eq)]
enum Style { Theme }
#[derive(PartialEq, Eq)]
enum Script { Site }

cx.head_mut().stylesheet(Style::Theme, "/styles/theme.css")?;
cx.head_mut().module(Script::Site, "/scripts/site.js")?;
cx.head_mut().remove_stylesheet(Style::Theme)?;
cx.head_mut().remove_module(Script::Site)?;
cx.head_mut().title("Checkout")?;
```

```html filename="Generated HTML"
<title>Checkout</title>
```

Removal preserves the slot position if a descendant fills it again. Only the title remains in this example.

## URL resolution

### URL base and mount

For this example, configure a public mount of `/shop` before rendering:

```rust filename="App configuration"
let head = HeadConfig::default()
    .with_urls(HeadUrlPolicy::new("https://shop.example", "/shop")?);
```

```rust filename="render_head"
cx.head_mut().canonical("/products/trail-jacket")?;
```

```html filename="Generated HTML"
<link rel="canonical" href="https://shop.example/shop/products/trail-jacket">
```

The leading `/` is still relative to the configured mount. Configure `HeadUrlPolicy::new(public_origin, mount)` before `with_defaults`: defaults resolve URLs immediately.

### External resource origins

Allow a CDN origin before using it for images, audio, video, stylesheets, or modules:

```rust filename="App configuration"
let urls = HeadUrlPolicy::new("https://shop.example", "/")?
    .allow_resource_origin("https://cdn.example")?;
let head = HeadConfig::default().with_urls(urls);
```

The public origin comes from trusted application configuration, including staging configuration. It is never inferred from `Host` or forwarded headers. Proa resolves and validates these URLs; it does not fetch resources.

## Other head tags

Keep charset, viewport, favicons, fonts, and other manual tags in the document's `html!` or `html_sync!` template, next to `{cx.head()}`. Proa does not parse or deduplicate manual tags. There is no automatic favicon or Open Graph image file convention.

## When mutations are allowed

Set metadata in `render_head` or in `HeadConfig::with_defaults`. A Page declares `ROLE = PAGE` and seals metadata before its body. An ancestor that supplies metadata declares `ROLE = LAYOUT`. Ordinary `COMPONENT` values skip head invocation.

These mutations also work in synchronous hooks returning `impl SyncHeadOperation` on `WebRenderSync`. Send components use `render_head_send` (or `render_head_send_sync` for synchronous rendering); an async Send hook must produce a Send future.

Page bodies, Suspense children, captures, and loading/error fallbacks cannot mutate metadata. A late mutation returns an error and invalidates the managed document, even if its `Result` is ignored. Invalid field values fail atomically and may be handled within a hook.

Each managed document needs one Page and one head outlet. Raw `child.render(cx)` calls render only the body; use template composition or framework render helpers for lifecycle dispatch. Run `cargo proa lint <changed-paths> --deny warnings` to catch async head overrides with missing roles or an explicit `COMPONENT` role. Synchronous hooks also retain a code-generation role assertion.
